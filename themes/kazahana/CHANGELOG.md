# Changelog

## 1.0.0

- First release: masthead header with a topic row and a mobile menu that works without JavaScript.
- Home with a pine intro block, newest note, recent notes grid, quote band and archive list.
- Single post with a table of contents, drop cap, author row and older/newer pair.
- Archive, topic, author and search lists with thumbnails and a Newer/Older pager; a 404 page.
- Pine footer with the site and topic menus and a subscribe link.
- Light and dark, following the system by default; settings for the intro, drop cap, header topics and dateline.
