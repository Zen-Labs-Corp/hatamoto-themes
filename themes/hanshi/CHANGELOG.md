# Changelog

## 1.0.0

First release.

- Homepage with a lead post, a numbered index and a topics grid, paged at `/?page=N`.
- Pagination ruler, numbered pager, go-to-page box and arrow-key paging on every listing.
- Post layout with an index sidebar (scroll spy, reading progress, minutes left), a mobile index bar, numbered headings, author box, tags and related posts.
- Archive, topic, author and search pages grouped by month.
- Generated pattern covers for posts without a featured image.
- Search palette on `/` and `⌘K`.
- Settings for the accent, heading font, spacing, corners, colour mode, homepage and masthead.
- Opts in to `builder.tokens` and the header, footer, single and archive layout parts.
