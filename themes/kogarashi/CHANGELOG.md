# Changelog

## 0.1.0

### Added

- Split-screen shell: a fixed midnight panel with the wordmark, headline, topics and footer, beside a scrolling content column.
- Home with a grid of post cards, a featured first card and pagination.
- Single post with the cover, title and byline in the panel, a reading column, tags and newer/older cards.
- Topic, tag, author, archive and page layouts, search and a 404 page.
- Burger menu with navigation, topics and a subscribe button.
- Dark mode derived from the owner colours, with a header toggle.
- Settings: `color_mode`, `panel_image`, `panel_side`, `grid_columns`, `show_excerpts` and `density`.
- Self-hosted Hanken Grotesk and Fraunces.
