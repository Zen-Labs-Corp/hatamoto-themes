# Changelog

## 0.2.0

- Comments: when the owner turns comments on, posts and pages show the comment form and the thread
  below the text, styled with the theme's own type and colours in light and dark.
- Needs a Hatamoto core with comments; older cores refuse to install this version.

## 0.1.0

- Initial release: a soft pastel blog theme in light and dark.
- Header, footer, home with a story rail, single post, archive and taxonomy, search and 404.
- Settings: colour mode, density, story rail, corner style, newsletter, post archive address, post contents.
