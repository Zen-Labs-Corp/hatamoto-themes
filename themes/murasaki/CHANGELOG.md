# Changelog

## 0.1.0

- First version: a studio theme for agencies and advisory firms.
- Oversized Bricolage Grotesque headings, numbered section eyebrows, hairline index rows and one vermilion accent.
- Styled home sections (hero, logo strip, features, stats, process, testimonials, FAQ, call to action), services, about and contact pages.
- Blog index, article and search, a work index and project page for portfolio sites, and a 404 page.
- Header with a no-JS mobile menu, optional header button, and a night footer with a giant wordmark.
- Light and dark modes (header toggle, remembered), AA contrast in both.
- Settings: colour mode, spacing, footer wordmark, section numbers, header button, hero accent.
