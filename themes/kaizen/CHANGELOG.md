# Changelog

## 0.2.0

- Comments: when the owner turns comments on, posts and pages show the comment form and the thread
  below the text, styled with the theme's own type and colours in light and dark.
- Needs a Hatamoto core with comments; older cores refuse to install this version.

## 0.1.0

- First version: a dark-first blog theme with a glowing horizon hero, a numbered index
  with sticky months, a condensing header, smooth page transitions, a live status strip
  in the footer and a light palette. Settings: colour mode, latest entry card, status
  strip, footer wordmark.
