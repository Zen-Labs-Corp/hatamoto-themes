# Changelog

## 0.1.0

- First version.
- Layouts: home, post archive, category and tag, author, single post, search, 404, header, footer and mobile menu.
- Split serif masthead, sticky category sidebar (chips on small screens) and a two-column card grid with tinted panels.
- Settings: colour mode, spacing, split masthead, tinted cards, show author, button label and address, footer quote, home page sections, archive address.
- Light and dark, with the lime primary after dark; follows the system by default and works without JavaScript.
- Fonts: Bricolage Grotesque and Source Serif 4, self-hosted (OFL).
